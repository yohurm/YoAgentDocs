# 开工前

- [ ] 目标、范围、非目标已对齐（否则先问）
- [ ] 已判断**能力类型**与**平台**（可叠加），并打开对应 `rules/by-type/`
- [ ] 已装载 `rules/common/` 与原则
- [ ] 已确认验证条件（例如 Android 是否已接真机、桌面应用能否启动）
- [ ] 若是具名仓库，已检查是否存在 `rules/by-project/<id>/`
- [ ] 不把本次一次性要求写进常驻规则
