# 修缺陷

- [ ] 本轮问题已列清单；每条都有对应验收标准
- [ ] 已复现或写明无法复现的原因
- [ ] 已沿该现象完整数据链路定位；根因落在明确的一层
- [ ] 修复在该层，无新的绕过包装、兼容性代码或兼容层
- [ ] 无空判断掩盖上游、无吞异常、无延时/重试/标志位躲时序、无只改 UI 藏错数据
- [ ] 清单上每条都已按类型包验收通过（真机/启动/测试等门禁满足）；没有「主流程过了先交」
- [ ] 未把未验证写成已验证；环境缺口已写明且未当作完成
- [ ] 未扩大到无关模块
- [ ] 未在未全部达标前写收尾总结或结束对话
