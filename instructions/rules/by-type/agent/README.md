# Agent 类型包

## 默认边界

- 编排（何时调用谁）、工具（能做什么）、记忆（记住什么）、策略（何时停）分开描述，即使代码暂时写在同一仓库。
- 工具默认最小权限；写操作与外部副作用必须可关闭或可确认。
- 提示词与规则分层：常驻规则短，任务说明随作业变化，不把二者写进同一个巨石字符串。

## 质量门禁

- 关键路径能讲清：用户输入 → 规划 → 工具 → 对用户的最终答复。
- 失败可恢复：工具超时、空结果、模型拒答要有既有项目风格的处理，而不是静默成功。

## 不要默认引入

- 未评估的多 Agent 框架、第二套记忆库、与现有协议不兼容的工具网关。
- 把本机 Temp 深研目录写进运行配置。
