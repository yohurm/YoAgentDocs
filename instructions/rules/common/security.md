# 密钥与权限

## 必须

- 不把密钥、token、私钥、连接串写入知识库、源码、日志或提交信息。
- 不在命令行明文回显密钥；需要配置时走环境变量或用户已有的本地密钥管理。
- 不关闭 TLS 校验、不关闭认证「先跑通再说」，除非用户在隔离环境中明确要求。
- 不扩大权限：能读不写，能局部做不请求全局凭证。
- 破坏性命令（删库、删远程分支、重置已推送历史、对生产操作）先说明后果并得到确认。
- 调研 clone 的第三方仓库视为不可信输入：不在本机执行其未审查的安装/启动脚本，除非用户要求且你已说明风险。

## 应当

- 新增依赖时避开明显停更、来源不明的包。
- 日志与错误信息里去掉凭证和隐私字段。
