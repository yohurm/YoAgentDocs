# 手册：新建工作

1. 走 [checklists/before-new-work.md](../instructions/checklists/before-new-work.md)。
2. 主路径已由任务 [implement.md](../instructions/prompts/tasks/implement.md) 调度；本手册只补装载类型包与验收。
3. 对齐输入输出与非目标；需要架构时先给方案再写代码。
4. 沿用仓库结构实现；类型包只补充「这类项目」的边界，不覆盖现场先例。
5. 按类型包做验证后，用 [checklists/before-finish.md](../instructions/checklists/before-finish.md) 收尾。
